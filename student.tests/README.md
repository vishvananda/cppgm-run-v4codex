# Student tests

Use this directory for your own test inputs and small test harnesses. Run them
explicitly with the tool for the assignment you are working on; default test
targets discover only `paN/tests/`.

Required course fixtures belong in the earliest owning assignment's
`paN/tests/` directory. This directory contains no unspecified-outcome fixtures
or reference oracles. See [Testing and references](../TESTING_AND_REFERENCES.md).

The PA1–9 history was rebased onto the clean v4 export. Current plans, audits
and reproduction commands use the new commit IDs; raw historical measurements
retain their original IDs. [The commit map](commit-rebase-map.json) relates them;
the compiler source tree is identical at every mapped pair.
