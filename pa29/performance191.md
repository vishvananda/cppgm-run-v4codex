## Corrected-owner scaling

The [owner dataset](../student.tests/pa29/evidence191/owner-performance.json), generated by [performance191.py](../student.tests/pa29/performance191.py), retains six exact sources and eight compiler plus eight runtime samples each (96 observations). The frozen entry compiler rejects every source, and the diagnostics/statuses are retained. These are corrected-only measurements, never a speedup comparison against an incorrect executable. Clang independently compiles and executes all six inputs.

`demandN` demands 128/512/2048 distinct vector function specializations. Each contributes to the checked result, then a live two-million-iteration vector XOR/reduction recurrence uses a seed from argv and a Python-computed checksum. `widthN` holds 128 function definitions fixed while vector lanes grow 16/64/256. Runtime performs about four million lane additions in each case, passing vectors through a function and reducing every result. Python computes the independent checksum. O0, runtime inputs and observed reductions keep the work live.

## Preserved preliminary and inherited evidence; budgets

The [preliminary common dataset](../student.tests/pa29/evidence191/preliminary-common-performance.json) preserves 224 additional observations at code tip `37d03290`; [preliminary launchers](../student.tests/pa29/evidence191/preliminary-owner-launchers.json) preserve 16 samples. The first owner preflight exposed a retained-template initializer defect, recorded with its source and diagnostic in [preliminary-owner-failure.json](../student.tests/pa29/evidence191/preliminary-owner-failure.json). Related constructor-member controls exposed the same missing initializer-plan routing. Both owners were repaired at the final code tip and all final measurements/checks rerun. No old result is silently rebound to the new compiler. Total new retained timing evidence is **544 observations plus 32 launchers**.

All [audit190 measurements](performance190.md), including its 656 observations/16 launchers and the 2,936 historical observations/56 launchers it verified, remain unchanged. Historical failures and diagnostic targets remain visible. Current-stage spec §9 reclassifies blanket inherited 15% latency/RSS and zero-growth targets as diagnostic, not extra PA29 gates. This does not waive a failing contract test or a mandated limit.

This change supplies required typed representation and lowering; it adds no optional optimization pass. Straight-line scalar lowering is capped at eight lanes, with one ordinary loop beyond that cap. This bounds compiler work and text growth while retaining O(lanes) runtime semantics; the measured width series confirms the bound. Bit casts use the existing bulk-copy owner, and omitted vector initializer suffixes use bulk zeroing. Constant vector traversal is capped at one million lanes and charges active interpretation. Existing constexpr one-million-step/depth-512 limits, forced-inline depth 64/work 262,144 per caller and 4,194,304 per preparation, native storage bounds and course timeouts are unchanged. No profiler or allocator-specific diagnostic becomes an exit gate.

Necessary semantics are measured on valid output; no profit is claimed against entry failures. PA30–34 hosted/runtime/optimizer/allocation/inception obligations remain with those stages. The four remaining PA29 failures continue to count, and advancement still requires full PA29/root-through success.
