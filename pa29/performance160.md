# PA29 implementation160 performance evidence

Code: `2fd6963e`; entry: `8bdc6bbf`. O0 required semantic capability;
no optional optimization and no speedup claim. [Ownership and complexity](implementation160.md)
explain the work. [Manifest](../student.tests/pa29/evidence160/manifest.json)
records frozen binary/input/script hashes, flags, platform and raw observations.

## Protocol and equivalent common workloads

The binaries were frozen before timing. Compilation and checked execution are
measured separately with CPU affinity 0 and `/usr/bin/time` peak RSS. No build or
test process overlaps timing. External host scheduling is uncontrolled. Host g++
only links student-produced objects. Flags are `-O0 -c --stats`; host build flags
are `-std=gnu++11 -Wall -O3`.

Each common experiment retains 224 observations: A/A calibration followed by six
ABBA blocks for four workloads in compilation and runtime modes. The inputs keep
2,400 demanded template functions plus loops, calls, memory, floating point and
exceptions; runtime argc feeds independently checked results. All four objects
and executables are byte-identical A/B, and semantic/native work counts agree.
Large timing variation in the first experiment prompted one confirmation with
unchanged binaries, flags, input hashes and affinity. Both runs are retained.

Times below are medians; RSS is maximum KiB. Paired ratios use the two B versus
two A observations in each ABBA block; brackets show the full paired range.

## Stage acceptance and budgets

No optional transform was added: its new work and growth budgets remain **zero**.
Compiler binary size changes from 3944808 to 3962664 bytes (+17856); common generated text
growth is zero. New-capability text grows only with required emitted functions.
Existing constexpr step/depth budgets, native frame/alignment limits and course
timeouts are preserved. Memory and latency needed for correct receiver and
conversion facts are stage-scoped correctness costs, not an optimization claim.

The evidence shows bounded semantic work and no repeatable avoidable regression
on the common workloads. Historic blanket 15% latency/RSS and zero-growth goals
remain diagnostic targets under spec §9, not permanent exit gates. All earlier
measurements are preserved. Optimization/allocation and self-hosting retain
PA32–34 owners. This accepts the invocation group only: PA29 remains at 323/403.
